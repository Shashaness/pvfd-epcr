# PVFD ePCR Flutter application

This is the Flutter application subdirectory. Start with the repository-root [README](../README.md), [build instructions](../docs/BUILDING.md), [contribution guidelines](../CONTRIBUTING.md) and [security policy](../SECURITY.md).

Run Flutter commands from this directory. The sole supported entry point is `lib/main.dart`.

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

This is an experimental development project. Do not install onto an operational tablet or use actual patient information without the reviews described in the root documentation.
